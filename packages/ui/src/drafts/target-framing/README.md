# Target-framing workshop fixtures

These photographs are reference artwork for the draft product example, not
camera exposures, calibrated survey tiles, or predictions of image quality.
The displayed frame and sky paths are illustrative. Target scale, orientation,
altitude and viewing windows do not describe Chris's rig or actual sky.

The downloaded JPEGs are unchanged; the specimen crops them for presentation.
Images are bundled locally so the interaction does not depend on remote image
requests. This is a design fixture, not a decision about the production catalog
or survey provider.
