# Workshop image fixture

`capture-star-field.png` is the full 1600×1200 monochrome display preview from
Vela's local rig simulator, captured on 2026-09-05 with a two-second exposure.
It was read from the isolated offline alignment review server's retained image;
no physical rig was used. The simulator generated the pixels from the locally
provisioned D05 star catalog, and Vela applied its existing display stretch.

The Capture specimen uses this single static image for visual and interaction
design. Its selectable exposure times and capture states are illustrative;
they do not regenerate the pixels or contact the simulator. The image is not
evidence of acquisition, photometric realism, focus quality, or sky conditions.
